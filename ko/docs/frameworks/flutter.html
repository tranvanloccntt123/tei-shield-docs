Flutter 통합

tei_shield_flutter plugin은 pub.dev에서 배포됩니다. Flutter autolinking으로 Android/iOS를 등록하고 MethodChannel('dev.tei/shield')를 사용합니다. Android는 Maven Central에서 SDK io.github.tranvanlocntt123:shield:0.1.0을 resolve하고 iOS XCFramework는 package에 포함됩니다. Bridge가 native SDK를 호출하고 Dart가 client와 automatic run policy를 관리합니다.

요구사항은 Dart >= 3.6, Flutter >= 3.27, Android API >= 26 / JDK 17, iOS >= 15 / Swift 5.9입니다. Example은 Flutter 3.41.6에서 확인했습니다. Plugin은 XCFramework에 CocoaPods를 사용하므로 Flutter host가 Swift Package Manager를 켜도 Flutter guide에 따라 CocoaPods fallback을 유지하세요.

Plugin 설치​

flutter pub add tei_shield_flutter

또는 pubspec.yaml에 추가합니다.

pubspec.yaml
dependencies:
  tei_shield_flutter: ^0.1.9
flutter pub get

플랫폼 구성​

  • Android: android/app/build.gradle.kts 또는 android/app/build.gradle에서 minSdk = 26 이상을 설정합니다. AAR는 arm64-v8a와 x86_64만 지원합니다. 
    flutter build apk --target-platform android-arm64,android-x64
    AAB에서는 ndk.abiFilters에 ABI를 설정합니다. Flutter host repositories에는 google()과 mavenCentral()이 필요합니다.
  • iOS: Runner와 ios/Podfile에서 iOS 15+를 설정합니다. 
    cd ios && pod install && cd ..
    TEIShield를 SPM으로 다시 추가하지 마세요. plugin podspec이 binary XCFramework를 link/embed합니다.

일회성 check​

import 'package:tei_shield_flutter/tei_shield_flutter.dart';

final emulator = await TeiShield.check(ShieldCheck.emulator);
final result = await TeiShield.assess(AssessmentOptions(
  checks: [ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
));
final empty = await TeiShield.assess(); // 빈 signals, observer 없음

ShieldCheck.values에는 native SDK의 12 detector가 모두 있습니다. 빈 list는 detector를 실행하지 않습니다. 잘못된 code/payload는 직접 MethodChannel을 호출해도 native가 거부합니다.

클라이언트 앱에서 구성​

final identity = AppIdentityConfig(
  expectedPackage: 'com.company.mobile',
  signingCertificateSha256: [releaseCertificateSha256, nextCertificateSha256],
);
final client = await TeiShieldClient.initialize(
  options: AssessmentOptions(
    checks: [ShieldCheck.appIdentity, ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
    appIdentity: identity,
  ),
  runPolicy: const ShieldRunPolicy(
    assessOnInitialize: true,
    reassessOnForeground: true,
  ),
);

appRiskPolicy.consume(client.lastAssessment!);
final subscription = client.assessments.listen(
  appRiskPolicy.consume,
  onError: reportAssessmentFailure,
);

final configured = await client.assess();
final once = await client.assess(AssessmentOptions(checks: [ShieldCheck.debugger]));
final all = await client.assess(AssessmentOptions(checks: ShieldCheck.values, appIdentity: identity));
final signer = await client.check(ShieldCheck.appIdentity);

await subscription.cancel();
await client.close();

Certificate、policy、error handler는 앱이 제공합니다. Bridge는 certificate를 hard-code하지 않습니다. appIdentity 선택 시 Android에는 non-empty package와 lowercase 64-character digest가 필요합니다. Key rotation에는 여러 digest를 전달할 수 있습니다. iOS는 appIdentity: unsupported를 반환합니다.

API / option동작
AssessmentOptionschecks/certificate를 immutable collection으로 복사
ShieldRunPolicy두 flag의 default는 false
client.assess()저장된 selection 사용
client.assess(options)한 번만 다른 selection 사용, default 변경 없음
client.check(check)client default identity로 detector 하나 실행
client.lastAssessment성공 전 null, 이후 최신 snapshot
client.assessments성공 결과 broadcast stream, automatic error는 stream error
client.close()observer/stream 제거, 늦은 request/result 거부

Manual error는 Future로 반환됩니다. Foreground를 켤 때 stream에 onError를 추가하세요. Auto check는 Flutter resumed 전환을 따르며 background service는 없습니다. Client는 request를 직렬화하고 중복 foreground event를 합칩니다.

Client는 app/session scope에 유지하세요. packages/tei-shield_flutter/example/lib/main.dart에 subscription cleanup 예제가 있습니다.

Application schema와 policy​

TeiShieldAssessment는 schemaVersion, signals, durationMs(double)를 포함합니다. Signal은 code, SignalStatus, string confidence를 가집니다. Plugin은 데이터를 유지할 뿐 앱을 차단하거나 threshold를 고르거나 server를 호출하지 않습니다. UI, telemetry, step-up, policy는 앱이 결정합니다.

unsupported/error를 pass로 바꾸지 마세요. iOS의 appIdentity, storeAttestation, missingMotionSensors, batteryUnavailable는 unsupported입니다. trust model을 참고하세요.

Dart config error는 ArgumentError, native payload error는 TEI_SHIELD_INVALID_OPTIONS code의 PlatformException입니다. Web/desktop은 UnsupportedError를 반환합니다.

Example과 테스트​

cd packages/tei-shield_flutter
flutter pub get
flutter analyze
flutter test
cd example
flutter create --platforms=android,ios --project-name=tei_shield_example --org dev.tei .
flutter run

Example에는 emulator-only check와 default detector group이 있습니다. Dart test는 MethodChannel을 mock하며 native coverage는 verification checklist에 따라 실제 기기에서 확인합니다.
