Protocol helper và C ABI

Các tiện ích có trong source nhưng không triển khai enrollment, tạo evidence, ký request, transport hay server verification. Phần lớn app chỉ cần API assessment. Expo/Flutter không expose protocol helper hoặc C ABI.

Helper native​

Thao tácKotlin ProtocolSwift ShieldProtocol
SHA-256sha256(bytes: ByteArray): ByteArraysha256(_ data: Data) -> Data
Hex lowercasehex(bytes): Stringhex(_ data) -> String
Base64 chuẩn có paddingb64(bytes): StringFoundation Data.base64EncodedString()
Base64url không paddingurl64(bytes): Stringbase64url(_ data) -> String
TEI1 framingencode(fields: List<String>): ByteArrayencode(_ fields: [String]) -> Data
RequestrequestFields(request, audience, timestamp, challenge, keyId) trả list, cần gọi encoderequestBytes(_:audience:timestamp:challenge:keyId:) trả bytes đã encode
EnrollmentenrollmentFields(audience, challenge, keyId, publicKey) trả field AndroidenrollmentBytes(audience:challenge:keyId:) trả bytes iOS, public key rỗng

Kotlin ProtectedRequest(method, target, body) và Swift try ProtectedRequest(method:target:body:) yêu cầu method gồm chữ ASCII hoa không rỗng; target ASCII printable bắt đầu /, không //, không # hay khoảng trắng. Target là raw path/query, không phải URL đầy đủ. Body ByteArray/Data được giữ nguyên. Kotlin sai input ném IllegalArgumentException; Swift ném ShieldError.invalidRequest.

import Foundation
import TEIShield

let request = try ProtectedRequest(
    method: "POST", target: "/v1/example?b=2&a=1",
    body: Data("{\"amount\":10}".utf8)
)
let bytes = ShieldProtocol.requestBytes(
    request, audience: "example-app",
    timestamp: "1788600000000", challenge: "example-only", keyId: "example-only"
)
// Chỉ minh họa framing; placeholder không phải proof hợp lệ.

Helper không xác nhận audience/key ID/challenge/timestamp có đến từ server đáng tin. Kotlin encode giới hạn 1.048.576 byte UTF-8 mỗi field nhưng không chặn số field. Swift dùng precondition tối đa 64 field và 1.048.576 byte/field; vi phạm sẽ trap, không trả error. Validation kích thước input chưa đáng tin phải làm trước. C encoder có giới hạn riêng bên dưới.

Model transport không phải service API​

Challenge gồm value, expiresAt, purpose. Kotlin public validate(expected) kiểm purpose, chuỗi 43 ký tự thuộc bảng chữ Base64url, ISO-8601 expiry còn hiệu lực. Swift có public initializer/Codable nhưng validate là internal, app ngoài module không gọi được.

Enrollment: platform, challenge, keyId, publicKey, evidence, signature. Kotlin mặc định platform android, có json(): JSONObject. RequestProof: platform, challenge, keyId, timestamp, evidence, signature. Kotlin header() và Swift try header() encode JSON thành Base64 chuẩn có padding, không phải Base64url. Encode không phải ký hay verify.

Swift Enrollment, RequestProof, Signal, Assessment là Codable nhưng source không khai báo public memberwise initializer. App ngoài module không nên dùng cú pháp memberwise tự sinh; decode transport model khi phù hợp, nhận assessment từ SDK.

Các case public ShieldError: unsupported, invalidRequest, expiredChallenge, missingKey, enrollmentAlreadyAttested, keychain(Int32), invalidResponse. Có tên lỗi không đồng nghĩa SDK assessment cung cấp enrollment/attestation. KeyStorage là internal.

Endpoint trong TEI1 wire protocol là contract server phải tự triển khai. Repository hiện không có thư mục server/ chạy được, provider verifier hay HTTP client cho các route đó.

C ABI​

Khai báo ở core/include/tei_shield.h. String đầu vào là UTF-8 bytes. Caller sở hữu output; không có buffer trả về cần SDK giải phóng.

HàmContract
tei_encode(fields, sizes, count, output, capacity)Trả số byte cần; output null/quá nhỏ thì không ghi. Pointer/length sai, hơn 64 field, field lớn hơn UINT32_MAX hoặc overflow trả 0. Không field vẫn encode bốn byte TEI1
tei_sha256(bytes, size, output)Ghi đúng 32 byte digest vào output caller cấp
tei_assess(output, capacity)Chạy bảy check native, trả JSON mảng signal, không phải object Assessment nền tảng
tei_assess_selected(mask, output, capacity)Chỉ chạy check được chọn; trả size gồm NUL, chỉ ghi khi đủ. Bit không hợp lệ trả 0, mask 0 serialize []
tei_tracer_present(status)Parse TracerPid:; -1 sai/thiếu/null, 0 không tracer, 1 có tracer

Flag bit 0–6: TEI_CHECK_DEBUGGER, TEI_CHECK_INJECTED_IMAGES, TEI_CHECK_SYSTEM_WRITABLE_MOUNT, TEI_CHECK_PRIVILEGED_FILES, TEI_CHECK_LIBC_POINTER, TEI_CHECK_SDK_TEXT_INTEGRITY, TEI_CHECK_TOOL_PORT. TEI_CHECK_ALL_NATIVE gộp chúng. Năm check nền tảng còn lại không có C flag.

#include "tei_shield.h"
#include <stdexcept>
#include <string>
#include <vector>

std::string assessSdkText() {
    std::vector<char> output(8192);
    for (int attempt = 0; attempt < 3; ++attempt) {
        const size_t needed = tei_assess_selected(
            TEI_CHECK_SDK_TEXT_INTEGRITY, output.data(), output.size());
        if (needed == 0) throw std::runtime_error("Invalid native check mask");
        if (needed <= output.size()) return std::string(output.data(), needed - 1);
        output.resize(needed);
    }
    throw std::runtime_error("Native assessment size kept changing");
}

Không parse buffer chưa được ghi/quá nhỏ, không coi return 0 là assessment rỗng thành công. Framing có thể sizing hai lượt; riêng assessment mỗi lời gọi đều chạy detector, kể cả output null, nên hai lượt có thể thấy trạng thái/size khác nhau. Golden vectors ở protocol/vectors.json, bản Swift ở ios/Tests/TEIShieldTests/vectors.json.
