Tích hợp iOS native

Bản phát hành iOS là một binary Swift Package từ tei-shield-ios, chứa TEIShield.xcframework cho iOS device và simulator. API công khai là Swift concurrency API.

Yêu cầu​

Thành phầnPhiên bản của SDK
Deployment targetiOS 15 trở lên
Swift5.9 trở lên
Artifact releaseGitHub Release 0.1.0 của tei-shield-ios
Package checksumSHA-256 trong Package.swift và release asset .sha256

Thêm binary Swift Package​

Trong Xcode chọn File → Add Package Dependencies, nhập URL sau, chọn version 0.1.0, rồi thêm product TEIShield vào app target:

https://github.com/tranvanloccntt123/tei-shield-ios.git

Package.swift của repository trỏ binary target đến asset TEIShield.xcframework.zip trong GitHub Release cùng tag. Cần tạo release 0.1.0 và upload archive trước khi Xcode có thể resolve package. Kiểm tra checksum của asset đã tải với swift package compute-checksum; giá trị phải khớp manifest package.

Trong lúc phát triển SDK hoặc khi chưa có release, có thể chọn Add Local… và trỏ đến artifacts/ios/ trong source repository. Thư mục này có Package.swift và TEIShield.xcframework.

Bản binary là lựa chọn cho release vì pipeline đã seal section code trước khi framework được ký bởi app tiêu thụ. Package.swift ở root repo dùng cho phát triển/test; source build không chạy seal sau link nên sdkTextIntegrity có thể là unsupported.

Khởi tạo và assessment​

ShieldStore.swift
import Combine
import TEIShield

@MainActor
final class ShieldStore: ObservableObject {
    @Published private(set) var assessment: Assessment?
    @Published private(set) var error: Error?

    private var sdk: TeiShield?

    func start() async {
        do {
            let instance = try await TeiShield.initialize(config: ShieldConfig())
            sdk = instance
            assessment = await instance.assess()
        } catch {
            self.error = error
        }
    }

    func stop() async {
        await sdk?.close()
        sdk = nil
    }
}

Dùng store từ SwiftUI:

struct ContentView: View {
    @StateObject private var store = ShieldStore()

    var body: some View {
        List(store.assessment?.signals ?? [], id: \.code) { signal in
            Text("\(signal.code): \(signal.status)")
        }
        .task { await store.start() }
    }
}

TeiShield là actor. Các lời gọi từ code không-isolated cần await cho initialize, assess và close. Trong ví dụ legacy, initialize(config:) đã assessment một lần; lời gọi assess() sau đó lấy snapshot mới.

Chọn detector​

Gọi trực tiếp khi app chỉ cần một detector hoặc một nhóm detector; các lời gọi này không giữ instance hay đăng ký notification observer:

let emulator = await TeiShield.check(.emulator)

let assessment = await TeiShield.assess(
    options: AssessmentOptions(checks: [.emulator, .sdkTextIntegrity]),
)

Một danh sách rỗng trả assessment rỗng; kết quả chỉ chứa detector được yêu cầu. Các detector không hỗ trợ trên iOS, gồm appIdentity, storeAttestation, missingMotionSensors và batteryUnavailable, trả unsupported khi được chọn.

let shield = await TeiShield.initialize(
    options: AssessmentOptions(checks: [.emulator, .sdkTextIntegrity]),
    runPolicy: ShieldRunPolicy(
        assessOnInitialize: false,
        reassessOnForeground: false,
    ),
)
// shield.lastAssessment is nil here.
let result = await shield.assess()

shield.assess(options:) chạy lựa chọn khác một lần và không thay đổi lựa chọn mặc định của instance.

Vòng đời ứng dụng​

initialize(config:) legacy tự lắng nghe UIApplication.willEnterForegroundNotification và assessment lại khi app trở lại foreground. Với API configurable, bật hành vi bằng ShieldRunPolicy(reassessOnForeground: true). Giữ instance ở scope của app/session. Không tạo lại SDK trong mỗi View hoặc mỗi lần body render.

Nếu app có nhiều scene, giữ store ở App/dependency container dùng chung và chỉ đóng khi session thực sự kết thúc. Simulator sẽ có signal emulator: detected; hãy tách signal này khỏi policy production và không dùng nó như bằng chứng jailbreak.

Privacy và signing​

Framework chứa PrivacyInfo.xcprivacy; app vẫn phải khai báo privacy manifest của chính mình theo các API khác mà app sử dụng. Framework được app consumer ký khi embed vào app; không cần private signing identity để đóng gói XCFramework.

Khi một check được chọn, appIdentity và storeAttestation trả unsupported: identity cuối cùng cần App Attest/server, và SDK chưa tạo/verify proof. emulator trả detected trên simulator, notDetected trên iOS device build. Các check không được chọn sẽ không xuất hiện trong kết quả.

Không chuyển unsupported thành notDetected trong adapter của app.

Nếu dùng source package​

Source package ở root repo hữu ích cho test protocol và phát triển nội bộ:

swift test

Đối với release, dùng binary package từ tei-shield-ios và kiểm tra checksum trước khi phân phối:

curl -L \
  https://github.com/tranvanloccntt123/tei-shield-ios/releases/download/0.1.0/TEIShield.xcframework.zip \
  -o /tmp/TEIShield.xcframework.zip
swift package compute-checksum /tmp/TEIShield.xcframework.zip

Nếu app cần App Attest, enrollment hoặc request signing, hãy triển khai lớp networking/server tương ứng theo TEI1 wire protocol. Đừng suy ra quyền truy cập server từ assessment local.
