Flutter 統合

tei_shield_flutter plugin は pub.dev から配布されます。Flutter autolinking で Android/iOS を登録し、MethodChannel('dev.tei/shield') を使用します。Android は Maven Central から SDK io.github.tranvanlocntt123:shield:0.1.0 を解決し、iOS XCFramework は package に含まれます。Bridge は native SDK を呼び、Dart が client と自動実行 policy を管理します。

要件は Dart >= 3.6、Flutter >= 3.27、Android API >= 26 / JDK 17、iOS >= 15 / Swift 5.9。Example は Flutter 3.41.6 で確認済みです。Plugin は XCFramework に CocoaPods を使用します。Flutter host が Swift Package Manager を有効にしていても、Flutter guide に従い CocoaPods fallback を残してください。

Plugin のインストール​

flutter pub add tei_shield_flutter

または pubspec.yaml に追加します。

pubspec.yaml
dependencies:
  tei_shield_flutter: ^0.1.9
flutter pub get

Platform 設定​

  • Android：android/app/build.gradle.kts または android/app/build.gradle で minSdk = 26 以上にします。AAR は arm64-v8a と x86_64 のみ対応します。 
    flutter build apk --target-platform android-arm64,android-x64
    AAB は ndk.abiFilters で対応 ABI を設定します。Flutter host の repositories に google() と mavenCentral() が必要です。
  • iOS：Runner と ios/Podfile で iOS 15+ を設定します。 
    cd ios && pod install && cd ..
    TEIShield を SPM から再度追加しないでください。Plugin podspec が binary XCFramework を link/embed します。

単発チェック​

import 'package:tei_shield_flutter/tei_shield_flutter.dart';

final emulator = await TeiShield.check(ShieldCheck.emulator);
final result = await TeiShield.assess(AssessmentOptions(
  checks: [ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
));
final empty = await TeiShield.assess(); // signals は空、observer なし

ShieldCheck.values は native SDK の 12 detector を含みます。空 list は detector を実行しません。不正な code/payload は直接 MethodChannel を呼んでも native が拒否します。

Client app から設定​

final identity = AppIdentityConfig(
  expectedPackage: 'com.company.mobile',
  signingCertificateSha256: [releaseCertificateSha256, nextCertificateSha256],
);
final client = await TeiShieldClient.initialize(
  options: AssessmentOptions(
    checks: [ShieldCheck.appIdentity, ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
    appIdentity: identity,
  ),
  runPolicy: const ShieldRunPolicy(
    assessOnInitialize: true,
    reassessOnForeground: true,
  ),
);

appRiskPolicy.consume(client.lastAssessment!);
final subscription = client.assessments.listen(
  appRiskPolicy.consume,
  onError: reportAssessmentFailure,
);

final configured = await client.assess();
final once = await client.assess(AssessmentOptions(checks: [ShieldCheck.debugger]));
final all = await client.assess(AssessmentOptions(checks: ShieldCheck.values, appIdentity: identity));
final signer = await client.check(ShieldCheck.appIdentity);

await subscription.cancel();
await client.close();

証明書、policy、error handler は app が提供します。Bridge に certificate は hard-code されません。appIdentity 選択時の Android には non-empty package と lowercase 64-character digest が必要です。Key rotation では複数 digest を渡せます。iOS は appIdentity: unsupported を返します。

API / optionBehavior
AssessmentOptionschecks/certificate を immutable collection に copy
ShieldRunPolicy2 flag の default は false
client.assess()保存済み selection を使用
client.assess(options)一度だけ別 selection、default は変更しない
client.check(check)client の default identity で 1 detector
client.lastAssessment成功前は null、以後 latest snapshot
client.assessments成功結果の broadcast stream、automatic error は stream error
client.close()observer/stream を閉じ、遅い request/result を拒否

Manual error は Future で返ります。Foreground を有効にする場合は stream に onError を追加してください。Auto check は Flutter の resumed transition に追従し、background service はありません。Client は request を serialise し、重複する foreground event をまとめます。

Client は app/session scope に保持します。packages/tei-shield_flutter/example/lib/main.dart に subscription cleanup の例があります。

Application schema と policy​

TeiShieldAssessment は schemaVersion、signals、durationMs（double）を含みます。Signal は code、SignalStatus、string confidence を持ちます。Plugin は data を保持するだけで、app を block、threshold を選択、server を呼びません。UI、telemetry、step-up、policy は app が決定します。

unsupported/error を pass に変換しないでください。iOS の appIdentity、storeAttestation、missingMotionSensors、batteryUnavailable は unsupported です。参照：trust model。

Dart configuration error は ArgumentError、native payload error は code TEI_SHIELD_INVALID_OPTIONS の PlatformException。Web/desktop は UnsupportedError を返します。

Example と test​

cd packages/tei-shield_flutter
flutter pub get
flutter analyze
flutter test
cd example
flutter create --platforms=android,ios --project-name=tei_shield_example --org dev.tei .
flutter run

Example には emulator-only check と default detector group があります。Dart test は MethodChannel を mock し、native coverage はverification checklistに従って実機で行います。
