Runtime note​

初回の iOS Simulator test-host launch は dependency を開く dyld で停止し、application code の前に終わりました。derived product を /tmp/tei-shield-ios-tests に再構築すると解決しました。Runtime test は framework で sdkTextIntegrity: notDetected と emulator: detected を確認しています。

Remaining device acceptance​

以下は developer configuration と physical device が必要で、まだ passed とはしていません。

  • Google Play test track、Cloud project、Application Default Credentials、signing digest を設定し、live Play Integrity enrollment/protected request を実行する。
  • 実際の Apple App ID で App Attest を有効化し、App ID prefix と Bundle ID を設定して development/production distribution を実機テストする。
  • Clean-device false positive、rooted/jailbroken lab device、real debugger、injected instrumentation、patched SDK text を検証し、negative と unsupported を分けて保存する。
  • 実 package で signing-key rotation、reinstall、restored backup、missing/invalidated key、lost enrollment response、reset/re-enrollment を検証する。
  • Networking layer で offline/provider outage、request reorder、session rotation、response loss を検証する。
  • 最古の supported device で p50/p95 assessment/signing time、CPU、memory、foreground transition を測定する。Crypto protection level と attestation latency は emulator から推測せず実測する。

Reproduction​

README の command を使用します。iOS framework runtime verification：

xcodebuild -project ios/TEIShield.xcodeproj -scheme TEIShieldSample \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath /tmp/tei-shield-ios-tests \
  CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- test

CI には C++、Kotlin、JNI、Swift、framework、packaging job が含まれます。Workflow は作成済みですが、この session では GitHub 上で実行していません。
