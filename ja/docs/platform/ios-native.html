iOS native 統合

iOS release は tei-shield-ios の binary Swift Package です。device と simulator 用の TEIShield.xcframework を含み、public API は Swift concurrency API です。

Requirements​

ComponentSDK version
Deployment targetiOS 15+
Swift5.9+
Release artifacttei-shield-ios GitHub Release 0.1.0
Package checksumPackage.swift と release .sha256 asset の SHA-256

Binary Swift Package を追加​

Xcode で File → Add Package Dependencies を選び、次の URL、version 0.1.0、product TEIShield を app target に追加します。

https://github.com/tranvanloccntt123/tei-shield-ios.git

Repository の Package.swift は同じ tag の GitHub Release にある TEIShield.xcframework.zip を指します。Xcode が resolve できるよう、先に release 0.1.0 と archive を用意します。swift package compute-checksum で manifest と一致することを確認してください。

開発中または release 前は Add Local… で artifacts/ios/ を指定できます。この directory には Package.swift と TEIShield.xcframework があります。

Release では binary package を使用します。Pipeline が framework の signing 前に code section を seal するためです。Root の Package.swift は開発/test 用で、source build では post-link sealing が行われず sdkTextIntegrity が unsupported になる可能性があります。

Initialize と assessment​

ShieldStore.swift
import Combine
import TEIShield

@MainActor
final class ShieldStore: ObservableObject {
    @Published private(set) var assessment: Assessment?
    @Published private(set) var error: Error?

    private var sdk: TeiShield?

    func start() async {
        do {
            let instance = try await TeiShield.initialize(config: ShieldConfig())
            sdk = instance
            assessment = await instance.assess()
        } catch {
            self.error = error
        }
    }

    func stop() async {
        await sdk?.close()
        sdk = nil
    }
}

SwiftUI から store を使用します。

struct ContentView: View {
    @StateObject private var store = ShieldStore()

    var body: some View {
        List(store.assessment?.signals ?? [], id: \.code) { signal in
            Text("\(signal.code): \(signal.status)")
        }
        .task { await store.start() }
    }
}

TeiShield は actor です。Non-isolated code から initialize、assess、close を呼ぶ場合は await が必要です。

Detector の選択​

Static API は instance を保持せず notification observer も登録しません。

let emulator = await TeiShield.check(.emulator)

let assessment = await TeiShield.assess(
    options: AssessmentOptions(checks: [.emulator, .sdkTextIntegrity]),
)

空 list は空 assessment を返します。iOS で unsupported な appIdentity、storeAttestation、missingMotionSensors、batteryUnavailable は選択時に unsupported を返します。

let shield = await TeiShield.initialize(
    options: AssessmentOptions(checks: [.emulator, .sdkTextIntegrity]),
    runPolicy: ShieldRunPolicy(
        assessOnInitialize: false,
        reassessOnForeground: false,
    ),
)
// shield.lastAssessment is nil here.
let result = await shield.assess()

shield.assess(options:) は一度だけ別 selection を実行し、default を変更しません。

Application lifecycle​

Legacy initialize(config:) は UIApplication.willEnterForegroundNotification を監視して foreground 復帰時に再 assessment します。Configurable API は ShieldRunPolicy(reassessOnForeground: true) で有効化します。Instance は app/session scope に保持し、各 View や body render で再作成しません。

複数 scene の場合は shared App または dependency container に store を置き、session 終了時だけ close します。Simulator の emulator: detected は production policy と分け、jailbreak evidence として使用しません。

Privacy と signing​

Framework には PrivacyInfo.xcprivacy が含まれますが、app 自身が使う他 API の privacy manifest は app が宣言します。XCFramework は consuming app が embed 時に signing します。

選択された appIdentity と storeAttestation は unsupported。Final identity は App Attest/server が検証し、SDK は proof を作成/検証しません。Simulator は emulator: detected、iOS device build は notDetected です。Unsupported を notDetected に変換しないでください。

Source package を使う場合​

Root の source package は protocol test と internal development 用です。

swift test

Release では tei-shield-ios の binary package を使い、分配前に checksum を確認します。

curl -L \
  https://github.com/tranvanloccntt123/tei-shield-ios/releases/download/0.1.0/TEIShield.xcframework.zip \
  -o /tmp/TEIShield.xcframework.zip
swift package compute-checksum /tmp/TEIShield.xcframework.zip

App Attest、enrollment、request signing が必要な場合は TEI1 wire protocol に従って networking/server layer を実装してください。Local assessment から server access を推測しないでください。
