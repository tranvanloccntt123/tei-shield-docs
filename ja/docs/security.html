Trust model と detector coverage

端末環境は untrusted です。Local negative result は、この check が今回 indicator を観測しなかったことだけを意味します。unsupported と error を trusted result に変換してはいけません。Check は code/status/confidence を生成するだけで、server operation を許可したり app を terminate したりしません。

この version は arbitrary PLT/GOT scan、全 system function の disassembly、cross-process memory access、Magisk-hide bypass、direct machine-code syscall を実装しません。Function owner の検査で全 inline hook を検出できるわけではありません。Check は SDK 自身の text を対象とし、host app の全 binary を対象としません。制限は成功した check として表現しません。

Detector の選択​

App は ShieldCheck と AssessmentOptions で detector を要求し、native core は選択された bit mask だけを受け取ります。Android で emulator を選んでも /proc、loaded image、certificate、sensor、battery は検査しません。未選択 check を notDetected と解釈せず、Assessment に signal がないことを「実行されなかった」と扱います。Integration guideを参照してください。

Native sensitive string は compile-time に XOR-obfuscate され、volatile decode と短命 buffer を使用します。これは選択された detector constant の基本的な strings 検査を防ぐもので、決意した reverse engineering を防ぐものではありません。Exported symbol、JSON key、OS build-property marker、documentation string は読めます。Private key や shared API secret は埋め込みません。Android Keystore security level は local に報告するだけで hardware key attestation と偽って扱いません。Play Integrity は public key を bind しますが StrongBox-backed とは証明しません。

Binary sealing​

最終リンクした ELF64/Mach-O64 の instruction section を hash します。64-byte reserved non-code record に magic、little-endian virtual address、size、SHA-256 を保存します。Build は measured region への通常 relocation を拒否します。Runtime check は hash 前に range が readable executable mapping 内か確認します。Unsealed build は unsupported。macOS では CMake が ad-hoc signing 前に seal し、Xcode が framework signing 前に seal します。Strip は measured bytes を保持し、artifact audit が packaging 後に検証します。

攻撃者が verifier と expected digest を patch すれば local integrity を bypass できます。Embedded manifest は local detection mechanism であり、独立した root of trust ではありません。Google/Apple evidence は server が独立して検証します。Source SPM build は seal step を実行しないため、release integrity check には生成済み binary package を使います。

Server policy​

Google verdict は request hash、package name、全 current signing certificate digest、timestamp、PLAY_RECOGNIZED、MEETS_DEVICE_INTEGRITY、LICENSED と一致する必要があります。Signing-key rotation 中は旧/新 digest を許可し、古いものは意図的に削除します。Play App Signing certificate と upload-key certificate は異なります。

App Attest validation は node-app-attest の pinned root から Apple certificate chain、validity date、nonce、key ID、credential ID、RP ID hash、zero enrollment counter、exact environment を確認します。Assertion は signature、RP ID、strictly increasing counter を検証します。Development は development evidence のみ、production は production のみを受け入れます。DeviceCheck に黙って置き換えません。Apple verifier dependency は version-locked なので upgrade 前に provider protocol/library changes を確認します。

Sample に mock-provider switch はありません。Test fake は server/test/ に限定されます。Demo authentication は development-only。Production は実際の Authenticate callback、stable user ID、session rotation 時に変化する session ID、managed credential、TLS、database access control、redacted telemetry を用意する必要があります。Store は client が主張する hardware/security level を信頼しません。
