Trust model 和 detector 覆盖范围

设备环境不可信。本地 negative result 只表示这一次检查没有观察到对应 indicator。unsupported 和 error 绝不能转换为 trusted result。Check 只产生 code/status/confidence，不授权 server operation，也不终止 app。

CapabilityAndroidiOS store build
Debugger严格解析 TracerPidUnsupported；不使用 private ptrace API
Injected images/proc/self/maps name heuristicPublic dyld image enumeration
Hooked functionslibc open owner + SDK code checksumSDK code checksum；不支持通用 function hook
Root/jailbreakRead-only privileged-file probe、system/vendor mount flag仅 injected-image heuristic；不支持 filesystem/mount privilege probe
App identity所有 current signer 都必须匹配 explicit allowlist 和 package IDLocal bundle identity 不作为 trust assertion；由 server 上的 App Attest 验证

SymbolsHidden C++ internals 和 ELF export mapHidden C++ internals；public Swift/C API 仍可见
Port scansUnsupported，不启用 probeUnsupported

此版本不实现任意 PLT/GOT scanning、所有 system function 的 disassembly、cross-process memory access、Magisk-hide bypass 或 direct machine-code syscall。检查 function owner 不能检测所有 inline hook。Check 覆盖 SDK 自身 text，不覆盖 host app 的每个 binary。这些限制会明确表示，而不会伪装成成功的 check。

选择 detector​

应用通过 ShieldCheck 和 AssessmentOptions 请求 detector；native core 只接收已选择的 native check bit mask。选择 Android emulator 不会读取 /proc、枚举 loaded image、检查 certificate、sensor 或 battery。未选择的 check 不应解释为 notDetected，它们不会出现在 Assessment 中。请参阅集成指南。

Native sensitive strings 在编译时使用 XOR obfuscate，并以 volatile decode 和短生命周期 buffer 处理。这只能防止对选定 detector constant 的基础 strings 检查，不能阻止有决心的 reverse engineering。Exported symbol name、JSON key、OS build-property marker 和文档字符串仍可读。不会嵌入 private key 或 shared API secret。

Binary sealing​

最终链接的 ELF64/Mach-O64 会对 instruction section 做 hash。64-byte reserved non-code record 保存 magic、little-endian virtual address、size 和 SHA-256。Build 会拒绝指向 measured region 的普通 relocation。Runtime check 在 hashing 前确认配置范围位于可读 executable mapping 内。未 seal 的 build 报告 unsupported。macOS 上 CMake 在 ad-hoc signing 前 seal；Xcode 在 framework signing 前 seal。Strip 会保留 measured bytes；artifact audit 会在 packaging 后验证。

如果攻击者 patch verifier 和 expected digest，可以绕过 local integrity。Embedded manifest 是 local detection mechanism，不是独立的 root of trust。Google/Apple evidence 由 server 独立检查。Source SPM build 不执行 seal step；release integrity check 应使用生成的 binary package。

Server policy​

SDK 只返回 local signal。Backend 集成需另行提供认证、evidence 生成和独立验证、challenge 存储、replay 防护及业务 policy。本 repository 没有 server/ 实现或 provider test suite。Wire protocol 是契约建议；protocol helper 说明现有 utility。选择 storeAttestation 不会调用 provider。
