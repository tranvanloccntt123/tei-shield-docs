Flutter 集成

tei_shield_flutter plugin 通过 pub.dev 分发。它通过 Flutter autolinking 注册 Android/iOS，并使用 MethodChannel('dev.tei/shield')。Android 从 Maven Central 解析 SDK io.github.tranvanloccntt123:shield:0.1.0；iOS XCFramework 包含在 package 中。Bridge 直接调用两个 native SDK，Dart 管理 client 和自动运行 policy。

要求：Dart >= 3.6、Flutter >= 3.27、Android API >= 26 / JDK 17、iOS >= 15 / Swift 5.9。示例使用 Flutter 3.41.6 检查。Plugin 使用 CocoaPods 加载 XCFramework；即使 Flutter host 启用 Swift Package Manager，也要按照 Flutter guide 为此 plugin 保留 CocoaPods fallback。

安装 plugin​

flutter pub add tei_shield_flutter

或在 pubspec.yaml 中添加：

pubspec.yaml
dependencies:
  tei_shield_flutter: ^0.1.9
flutter pub get

平台配置​

  • Android：在 android/app/build.gradle.kts 或 android/app/build.gradle 中设置 minSdk = 26 或更高。AAR 只支持 arm64-v8a 和 x86_64： 
    flutter build apk --target-platform android-arm64,android-x64
    构建 AAB 时在 ndk.abiFilters 中配置对应 ABI。Flutter host 的 dependencyResolutionManagement.repositories 需要 google() 和 mavenCentral()。
  • iOS：Runner 和 ios/Podfile 中设置 iOS 15+： 
    cd ios && pod install && cd ..
    不要通过 SPM 再次添加 TEIShield；plugin podspec 会 link/embed binary XCFramework。

单次检查​

import 'package:tei_shield_flutter/tei_shield_flutter.dart';

final emulator = await TeiShield.check(ShieldCheck.emulator);
final result = await TeiShield.assess(AssessmentOptions(
  checks: [ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
));
final empty = await TeiShield.assess(); // 空 signals；没有 observer

ShieldCheck.values 包含 native SDK 的全部 12 个 detector。空列表不会运行 detector。Native 会拒绝无效的 check code 或 payload，包括直接调用 MethodChannel 的情况。

从客户端配置​

final identity = AppIdentityConfig(
  expectedPackage: 'com.company.mobile',
  signingCertificateSha256: [releaseCertificateSha256, nextCertificateSha256],
);
final client = await TeiShieldClient.initialize(
  options: AssessmentOptions(
    checks: [ShieldCheck.appIdentity, ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
    appIdentity: identity,
  ),
  runPolicy: const ShieldRunPolicy(
    assessOnInitialize: true,
    reassessOnForeground: true,
  ),
);

appRiskPolicy.consume(client.lastAssessment!);
final subscription = client.assessments.listen(
  appRiskPolicy.consume,
  onError: reportAssessmentFailure,
);

final configured = await client.assess();
final once = await client.assess(AssessmentOptions(checks: [ShieldCheck.debugger]));
final all = await client.assess(AssessmentOptions(checks: ShieldCheck.values, appIdentity: identity));
final signer = await client.check(ShieldCheck.appIdentity);

await subscription.cancel();
await client.close();

releaseCertificateSha256、nextCertificateSha256、appRiskPolicy 和 reportAssessmentFailure 由 app 提供。Bridge 不硬编码 certificate。选择 appIdentity 时 Android 要求非空 package 和小写 64 字符 digest；signing-key rotation 时可传多个 digest。iOS 返回 appIdentity: unsupported，但提供 identity 时仍会检查其 shape。

API / option行为
AssessmentOptions将 checks/certificate 复制为 immutable collection
ShieldRunPolicy两个 flag 默认 false，由 app 选择初始和/或 foreground run
client.assess()使用已保存的 selection
client.assess(options)单次使用新 selection，不 merge 或替换 default
client.check(check)使用 client default identity 运行一个 detector
client.lastAssessment成功运行前为 null，之后保存最新 snapshot
client.assessments成功结果的 broadcast stream；自动错误进入 stream error
client.close()移除 observer、关闭 stream、拒绝晚到的 request/result

手动调用的错误通过 Future 返回。启用 foreground check 时为 stream 添加 onError。自动检查跟随 Flutter 的 resumed 状态；没有 background service，也不会注册额外 native observer。Client 会串行化 request，并在自动运行未完成时合并连续 foreground event。close() 不会中断已在 native 中运行的 detector，但会移除 in-flight 和 queued result。

将 client 保持在 app/session scope。参阅 packages/tei-shield_flutter/example/lib/main.dart 了解 subscription cleanup 和 widget 在 initialize 完成前 dispose 的处理。

应用 schema 和 policy​

TeiShieldAssessment 包含 schemaVersion、signals 和 durationMs（double）。每个 signal 有 code、SignalStatus（detected、notDetected、unsupported、error）和 string confidence。Plugin 保留数据，不会阻止 app、选择阈值或调用 server。UI、telemetry、step-up 和 policy 由 app 决定。

不要将 unsupported/error 转成 pass。iOS 上 appIdentity、storeAttestation、missingMotionSensors、batteryUnavailable 返回 unsupported。Android 当前也没有 storeAttestation proof。参阅 trust model。

Dart 配置错误返回 ArgumentError；native payload 错误返回 code 为 TEI_SHIELD_INVALID_OPTIONS 的 PlatformException。Android engine detach 时不会接收晚到 callback，重新 attach 会创建新的 coroutine scope。Web/desktop 返回 UnsupportedError。

运行 example 和测试​

cd packages/tei-shield_flutter
flutter pub get
flutter analyze
flutter test
cd example
flutter create --platforms=android,ios --project-name=tei_shield_example --org dev.tei .
flutter run

Example 有 emulator-only check 和默认 detector group。Dart test 使用 mock MethodChannel 检查 serialization、identity、override、stream/lifecycle 和 close；native coverage 需按验证 checklist使用 Android/iOS build 和真实设备。

也可使用 flutter test integration_test/shield_test.dart -d <device-id> 在 emulator/simulator 上运行 native integration test，覆盖空 selection、emulator、store attestation state 和 native-boundary validation。
