Tích hợp Flutter

Plugin tei_shield_flutter được phân phối chính thức qua pub.dev. Plugin đăng ký Android/iOS bằng Flutter autolinking và dùng MethodChannel('dev.tei/shield'). Binary native (AAR và XCFramework) đã được đóng gói sẵn bên trong package. Bridge gọi trực tiếp hai SDK native; Dart quản lý client và chính sách chạy tự động.

Yêu cầu Dart >= 3.6, Flutter >= 3.27, Android API >= 26 / JDK 17, iOS >= 15 / Swift 5.9. Example được kiểm tra với Flutter 3.41.6. Plugin dùng CocoaPods cho XCFramework; Flutter host bật Swift Package Manager vẫn cần CocoaPods fallback cho plugin này theo hướng dẫn Flutter.

Cài đặt plugin​

Cài đặt package trực tiếp từ pub.dev:

flutter pub add tei_shield_flutter

Hoặc thêm vào file pubspec.yaml:

pubspec.yaml
dependencies:
  tei_shield_flutter: ^0.1.0

Chạy lệnh để tải dependencies:

flutter pub get

Cấu hình nền tảng​

  • Android:

    • Đặt minSdk = 26 (hoặc cao hơn) trong android/app/build.gradle.kts (hoặc android/app/build.gradle).
    • Binary AAR chỉ hỗ trợ kiến trúc arm64-v8a và x86_64. Build APK với: 
      flutter build apk --target-platform android-arm64,android-x64
      hoặc cấu hình ABI tương ứng trong ndk.abiFilters khi build AAB.
    • Maven dependency mang theo coroutines/lifecycle từ POM. Với Gradle PREFER_SETTINGS hoặc FAIL_ON_PROJECT_REPOS, đặt teiShield.useHostRepositories=true trong gradle.properties và thêm đường dẫn Maven repository của plugin vào dependencyResolutionManagement.repositories. Host cũng cần google() và mavenCentral(). Có thể trỏ registry nội bộ của app và đặt teiShield.androidDependency=dev.tei:shield:0.1.0 (hoặc version có cùng API bridge) để thay binary Android. Không dùng implementation files('...aar') trong library plugin.

  • iOS:

    • Đặt deployment target iOS 15+ ở Runner và platform :ios, '15.0' hoặc cao hơn trong ios/Podfile.
    • Cài đặt Pods: 
      cd ios && pod install && cd ..
    • Khi Flutter tạo Podfile tự động, giữ target của project ở 15+ trước lần build đầu. Không thêm TEIShield lần nữa qua SPM: podspec của plugin đã tự động link và embed binary XCFramework.

Kiểm tra một lần​

import 'package:tei_shield_flutter/tei_shield_flutter.dart';

final emulator = await TeiShield.check(ShieldCheck.emulator);
final result = await TeiShield.assess(AssessmentOptions(
  checks: [ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
));
final empty = await TeiShield.assess(); // signals rỗng, không có observer

ShieldCheck.values chứa đủ 12 detector tương ứng SDK native. Danh sách rỗng không chạy detector nào. Native từ chối mã check hoặc payload không hợp lệ, kể cả khi gọi thẳng MethodChannel.

Tùy biến từ client app​

final identity = AppIdentityConfig(
  expectedPackage: 'com.company.mobile',
  signingCertificateSha256: [releaseCertificateSha256, nextCertificateSha256],
);
final client = await TeiShieldClient.initialize(
  options: AssessmentOptions(
    checks: [ShieldCheck.appIdentity, ShieldCheck.emulator, ShieldCheck.sdkTextIntegrity],
    appIdentity: identity,
  ),
  runPolicy: const ShieldRunPolicy(
    assessOnInitialize: true,
    reassessOnForeground: true,
  ),
);

// Stream không replay. Kết quả initialize được lưu ở lastAssessment.
appRiskPolicy.consume(client.lastAssessment!);
final subscription = client.assessments.listen(
  appRiskPolicy.consume,
  onError: reportAssessmentFailure,
);

final configured = await client.assess();
final once = await client.assess(AssessmentOptions(checks: [ShieldCheck.debugger]));
final originalDefaults = await client.assess();
final all = await client.assess(AssessmentOptions(checks: ShieldCheck.values, appIdentity: identity));
final signer = await client.check(ShieldCheck.appIdentity);

await subscription.cancel();
await client.close();

releaseCertificateSha256, nextCertificateSha256, appRiskPolicy, reportAssessmentFailure do app cung cấp. Bridge không có certificate hard-code. Android yêu cầu cấu hình khi chọn appIdentity; digest phải lowercase hex đúng 64 ký tự, package không rỗng. Có thể truyền nhiều digest khi xoay signing key. iOS trả appIdentity: unsupported, không cần identity; nếu cung cấp thì cấu hình vẫn được kiểm tra shape.

API / tùy chọnHành vi
AssessmentOptionsCopy checks/certificate thành collection immutable
ShieldRunPolicyHai cờ mặc định false, app chọn chạy ban đầu và/hoặc foreground
client.assess()Dùng selection đã lưu
client.assess(options)Selection riêng cho một lần, không merge hay thay default
client.check(check)Chạy một detector với identity mặc định của client
client.lastAssessmentnull trước lần chạy thành công, chứa snapshot mới nhất sau đó
client.assessmentsBroadcast stream cho kết quả thành công; lỗi tự động đi qua stream error
client.close()Gỡ WidgetsBindingObserver, đóng stream, chặn request/kết quả muộn

Lỗi của lời gọi thủ công được trả qua Future. Stream nên có onError khi bật foreground. Foreground tự động theo chuyển trạng thái của Flutter về resumed; không chạy khi chỉ attach lần đầu, không có background service và không đăng ký thêm observer của native SDK. Client serialize request và gộp foreground liên tiếp khi lần tự động trước chưa xong. close() không ngắt detector native đã chạy nhưng loại bỏ kết quả đang xử lý và request còn đợi. Tạo client mới để đổi default hoặc run policy.

Giữ client ở scope app/session. Xem packages/tei_shield_flutter/example/lib/main.dart để cleanup subscription và trường hợp widget dispose trước khi initialize xong.

Schema và policy của ứng dụng​

TeiShieldAssessment gồm schemaVersion, signals và durationMs (double). Mỗi signal có code, SignalStatus (detected, notDetected, unsupported, error) và confidence dạng string. Plugin giữ nguyên dữ liệu, không tự chặn app, chọn ngưỡng hoặc gọi server. App tùy biến UI, telemetry, step-up và policy dựa trên các signal.

Không chuyển unsupported/error thành pass. Trên iOS, appIdentity, storeAttestation, missingMotionSensors, batteryUnavailable trả unsupported. storeAttestation hiện cũng không có proof trên Android. Xem trust model.

Cấu hình Dart sai trả ArgumentError; native payload sai trả PlatformException với code TEI_SHIELD_INVALID_OPTIONS. Engine Android bị detach không nhận callback muộn và coroutine scope được tạo mới khi attach lại. Web/desktop trả UnsupportedError.

Chạy example và kiểm thử​

cd packages/tei_shield_flutter
flutter pub get
flutter analyze
flutter test
cd example
flutter create --platforms=android,ios --project-name=tei_shield_example --org dev.tei .
# Đặt minSdk 26 và iOS deployment target 15+ như phần cài đặt.
flutter run

Example có nút chạy emulator riêng hoặc nhóm detector mặc định. Test Dart mock MethodChannel để kiểm tra serialization, identity, override, stream/lifecycle và close; dùng build Android/iOS và thiết bị thật để kiểm tra native theo checklist kiểm chứng.

Có thể chạy test gọi native thực trên emulator/simulator từ example: flutter test integration_test/shield_test.dart -d <device-id>. Test kiểm tra selection rỗng, emulator, trạng thái store attestation và validation ở native boundary.
